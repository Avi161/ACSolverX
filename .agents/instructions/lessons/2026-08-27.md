# Lessons — 2026-08-27

### 2026-08-27 Keep forest and quotient metrics typed

- [TRAP] A lower bound for a reduced word in the stored forest alphabet `A/B/G` does not give the same lower bound for its canonical quotient label in the `c/t/T` alphabet. Never use a numerical length comparison across those two representations.
- [WORKS] Use forest-word distances only for forest incidence and boundary exclusion. For transported-label equality, work with the canonical quotient schemas or an exact label identity.

### 2026-08-27 Keep log mathematics shell-safe

- [TRAP] Passing backslash mathematics through shell-interpreted text introduced control bytes into `logs/27-08-2026.md` (`\\b` and `\\r` became backspace and carriage return).
- [WORKS] Write log text with `apply_patch`, prefer plain ASCII notation inside prose, and read back the changed line before committing the log binding.

### 2026-08-27 Import scratch proof modules explicitly

- [TRAP] `from .scratch import ...` fails in a guarded `python -c` process because it has no package parent.
- [WORKS] For a deliberately bounded guarded lookup, prepend the project-relative `.scratch` directory to `sys.path` and import the pinned module by its exact filename; keep the corrected run on the same narrow code path.

### 2026-08-27 Stage tracked ignored proof notes with the index

- [TRAP] Explicit `git add literature/...` can reject a modified tracked proof note because the parent proof directory is ignored by repository rules.
- [WORKS] For an already tracked proof checkpoint, use `git add -u -- <explicit tracked paths>` so staging updates the index without force-adding ignored untracked material.

### 2026-08-27 Keep ripgrep alternations literal for TeX searches

- [TRAP] A mixed regex alternation containing an unescaped TeX `\Phi` branch was parsed by `rg` as an invalid Unicode-property escape.
- [WORKS] Split TeX symbol searches into fixed-string `rg -F` queries or search the plain identifier first; do not mix raw TeX backslashes into an extended-regex alternation.

### 2026-08-27 Preserve TeX backslashes in JavaScript patch strings

- [TRAP] A JavaScript patch string consumed TeX backslashes in a Markdown math delimiter, so `apply_patch` could not match the literal context.
- [WORKS] Use `String.raw` for `apply_patch` payloads containing TeX; then read back the changed lines before continuing.

### 2026-08-27 Keep raw template delimiters out of patch payloads

- [TRAP] Markdown inline-code backticks inside a JavaScript `String.raw` template terminated the template and caused a syntax error before the patch ran.
- [WORKS] Split TeX-heavy and inline-code-heavy patches, or escape every template delimiter; prefer ordinary quoted strings for plain-ASCII log entries.

### 2026-08-27 Resolve scratch artifact names before targeted searches
