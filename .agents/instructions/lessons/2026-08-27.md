# Lessons — 2026-08-27

### 2026-08-27 Keep forest and quotient metrics typed

- [TRAP] A lower bound for a reduced word in the stored forest alphabet `A/B/G` does not give the same lower bound for its canonical quotient label in the `c/t/T` alphabet. Never use a numerical length comparison across those two representations.
- [WORKS] Use forest-word distances only for forest incidence and boundary exclusion. For transported-label equality, work with the canonical quotient schemas or an exact label identity.

### 2026-08-27 Keep log mathematics shell-safe

- [TRAP] Passing backslash mathematics through shell-interpreted text introduced control bytes into `logs/27-08-2026.md` (`\\b` and `\\r` became backspace and carriage return).
- [WORKS] Write log text with `apply_patch`, prefer plain ASCII notation inside prose, and read back the changed line before committing the log binding.

### 2026-08-27 Import scratch proof modules explicitly

- [TRAP] `from .scratch import ...` fails in a guarded `python -c` process because it has no package parent.
- [WORKS] For a deliberately bounded guarded lookup, prepend the project-relative `.scratch` directory to `sys.path` and import the pinned module by its exact filename; keep the corrected run on the same narrow code path.

### 2026-08-27 Stage tracked ignored proof notes with the index

- [TRAP] Explicit `git add literature/...` can reject a modified tracked proof note because the parent proof directory is ignored by repository rules.
- [WORKS] For an already tracked proof checkpoint, use `git add -u -- <explicit tracked paths>` so staging updates the index without force-adding ignored untracked material.

### 2026-08-27 Keep ripgrep alternations literal for TeX searches

- [TRAP] A mixed regex alternation containing an unescaped TeX `\Phi` branch was parsed by `rg` as an invalid Unicode-property escape.
- [WORKS] Split TeX symbol searches into fixed-string `rg -F` queries or search the plain identifier first; do not mix raw TeX backslashes into an extended-regex alternation.

### 2026-08-27 Preserve TeX backslashes in JavaScript patch strings

- [TRAP] A JavaScript patch string consumed TeX backslashes in a Markdown math delimiter, so `apply_patch` could not match the literal context.
- [WORKS] Use `String.raw` for `apply_patch` payloads containing TeX; then read back the changed lines before continuing.

### 2026-08-27 Keep raw template delimiters out of patch payloads

- [TRAP] Markdown inline-code backticks inside a JavaScript `String.raw` template terminated the template and caused a syntax error before the patch ran.
- [WORKS] Split TeX-heavy and inline-code-heavy patches, or escape every template delimiter; prefer ordinary quoted strings for plain-ASCII log entries.

### 2026-08-27 Resolve scratch artifact names before targeted searches

- [TRAP] A targeted `rg` assumed a restricted-normalizer filename that was not present, adding a noisy missing-path error to an otherwise valid search.
- [WORKS] Use `rg --files .scratch` to resolve the exact artifact name before including it in a multi-file search.

### 2026-08-27 Refine equal-base pumped predicates fail closed

- [TRAP] [SUPERSEDED] The proposed `n>=2` pure-increment cell had 14 label pairs whose templates agree at the base but have different pumped canonical blocks; initially this looked like a threshold boundary.
- [WORKS] [SUPERSEDED] Splitting `n=2` from `n>=3` preserved the same 14 failures, proving that threshold refinement alone was not the repair.

### 2026-08-27 Normalize commensurable powers to one primitive phase

- [TRAP] Path and slot-zero schemas used different cyclic rotations of the same primitive core, so equal all-power words had unequal block keys at every pump base.
- [WORKS] Pass one common primitive reference across all commensurable schema families; let the fixed conjugators absorb phase rotations before comparing canonical pumped blocks.

### 2026-08-27 Shield raw pumps by the first affine increment

- [TRAP] A raw-locality record added the total base power length to an already absolute pump split, double-counting the base copies and overstating the protected action horizon.
- [WORKS] Certify `split + increment * core_length > horizon`, verify the exact base-to-next raw signature, and require positive central-length slope; this proves that every later insertion occurs beyond the finite raw boundary.

### 2026-08-27 Escalate Git metadata writes in restricted workspaces

- [TRAP] A normal `git add` failed with `Unable to create .git/index.lock: Operation not permitted` because the workspace permitted proof-file writes but exposed `.git` read-only.
- [WORKS] Keep proof edits sandboxed, then use the approved escalated Git command only for the explicit staging, commit, pull, and push checkpoint requested by the user.

### 2026-08-27 Split same-path delete and add patches

- [TRAP] One `apply_patch` payload with both `Delete File` and `Add File` for the same path is rejected as `multiple operations target` that file.
- [WORKS] For a deliberate full rewrite, delete and add in two separate `apply_patch` calls, then read back the replacement before staging.

### 2026-08-27 Refresh context after shared-agent edits

- [TRAP] A ledger patch used context captured before a documentation agent's final write and failed exact-context verification.
- [WORKS] After stopping or receiving a shared-filesystem agent, read the edited region again before applying the coordinating patch.

### 2026-08-27 Anchor insertions at stable section boundaries

- [TRAP] A prose insertion patch depended on an exact wrapped sentence and failed when its line-break context differed.
- [WORKS] For Markdown insertions, anchor the patch on the next stable section heading or a short unique equation boundary, then verify the inserted section by readback.

### 2026-08-27 Derive fixture endpoints from source rows
