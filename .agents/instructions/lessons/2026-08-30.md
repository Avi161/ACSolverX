# Lessons learned — 30 August 2026

### 2026-08-30 Count convergence checkpoints by ancestry

[TRAP] Reading a newest-first path log in the wrong direction made the remote-ledger budget appear exhausted even though the budget rule was committed after Sections 3.99--3.106.

[WORKS] Locate the commit that introduces a convergence rule, then count only descendant commits which touch its scoped sections.  Earlier checkpoints never consume a prospective budget.

### 2026-08-30 Scope lint around preserved debt

[TRAP] Whole-file Ruff reported 27 pre-existing E701 findings in a certificate whose new test was already clean, so an unqualified lint result did not isolate the current patch.

[WORKS] Preserve unrelated formatting debt and rerun the same file with only the known pre-existing rule excluded.  Report both the baseline finding and the scoped passing result; do not reformat proof infrastructure opportunistically.

### 2026-08-30 Keep rectangular relation matrices handed

[TRAP] For a left relation module, a coefficient matrix `C` with `e=C*b` was initially treated as a left-linear map by column multiplication.  Over a noncommutative group ring that column map is right-linear, so the stated left-module cokernel was ill-handed.

[WORKS] Use row vectors and right multiplication `rho_C(x)=x*C` to obtain the left-module split surjection from `D*C=I`.  Complete a rectangular generating system through its free stabilized kernel, and use only the elementary/diagonal move dictionary from square-system theorems.

### 2026-08-30 Legal AC4 blocks preserve the rectangular kernel

[TRAP] Treating a stable `U direct-sum I_r` factorization as automatically ordered like a legally stabilized residual system placed the old zero/complement coordinate before the new AC4 basis rows, so its displayed first columns were not `diag(C,I_r)`.

[WORKS] AC4 adds a collapsible 1--2 pair and an identity block to both module basis and residual rows, preserving the rectangular kernel.  Move the old zero coordinate past new legal rows with an explicit tame permutation before reading the first columns; legal square completion is then equivalent to freeness of that unchanged rank-one kernel.

### 2026-08-30 Double-escape TeX in JavaScript patch strings

[TRAP] A single backslash before a TeX spacing command inside the JavaScript source passed to `apply_patch` was consumed by JavaScript, leaving the malformed superscript `^{,P}` in the Markdown source.

[WORKS] Double every TeX backslash in JavaScript patch strings and read back the exact edited equation.  Prefer notation that needs no spacing escape when the spacing is nonessential.

### 2026-08-30 Search literal TeX with fixed strings

[WORKS] Use separate fixed-string `rg -F -e ...` patterns for literal TeX tokens; do not place raw TeX braces in an ad hoc regular expression.

[WORKS] After every generated documentation patch, scan the touched file for bytes below ASCII space other than tab, newline, and carriage return before staging.  Read back the edited paragraph separately from the ordinary diff check.

### 2026-08-30 Endpoint localization is cell-relative

[TRAP] A terminal-neighborhood theorem for two tokens inside one anchored cell was promoted to a support-independent multiplier alphabet for mixed edges between two arbitrary non-target cells.  This made a cycle-specific Bass--Serre estimate look uniformly linear across the complete mixed graph.

[WORKS] Track the cell whose radius supplies every endpoint-localization hypothesis.  For a complete mixed graph, keep actual edge-dependent multiplier families unless a separate global localization lemma is proved.  Branch injectivity survives for each fixed multiplier, but the number of branches and their union's local degree need not be uniform.
