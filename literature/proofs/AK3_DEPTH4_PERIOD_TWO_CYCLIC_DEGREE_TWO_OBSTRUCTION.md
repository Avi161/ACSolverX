# A cyclic three-point quotient obstructs the source-coupled lift

## Status

The 16-entry source-coupled first-layer solution from the preceding result
does not lift through the next lower-central layer. Its 112-term degree-two
residual is not in
\[
\sum_{i=0}^4L_i(\Lambda^2M),
\qquad
M=\mathbb Z[Q/\langle c\rangle],
\quad Q=\langle c,t\mid c^2=1\rangle.
\tag{1}
\]
An exact three-point quotient separates it with no support or radius bound.

This obstruction concerns that first-layer solution and the 16 mod-2 classes
generated by the four currently certified homogeneous directions. It is not
a global obstruction on every compactly supported first-layer solution.

## 1. The finite quotient

Over \(\mathbb F_2\), let \(Q\) act on
\(\Omega=\{0,1,2\}\) by
\[
c=1,
\qquad
t=(0\ 1\ 2),
\tag{2}
\]
with base point 0. Since \(c0=0\), (2) induces a well-defined module map
\[
M\otimes\mathbb F_2\longrightarrow\mathbb F_2[\Omega],
\qquad
e_{q\langle c\rangle}\longmapsto e_{q0}.
\tag{3}
\]

Order the wedge basis by \((01),(02),(12)\), and define
\[
\Psi_{\mathrm{cyc}}(a_{01},a_{02},a_{12})
=a_{01}+a_{02}+a_{12}.
\tag{4}
\]
The \(Q\)-action permutes the three unordered pairs, so (4) is
\(Q\)-invariant. Every exact lifting operator has group-ring augmentation
zero:
\[
\varepsilon(L_0),\ldots,\varepsilon(L_4)=(0,0,0,0,0).
\tag{5}
\]
It follows for every \(y\in\Lambda^2M\) that
\[
\Psi_{\mathrm{cyc}}(L_i y)
=\varepsilon(L_i)\Psi_{\mathrm{cyc}}(y)=0.
\tag{6}
\]
Thus (4) annihilates the whole image in (1), not just a bounded-support
subspace.

## 2. Exact separation

Add the 16-entry syzygy \(z\), with \(z_1=e_{ct}\), to the canonical
eight-entry relation-module solution. Exact nonlinear replay gives a freely
reduced residual of length 322, a Schreier-kernel word of length 70, and a
degree-two residual \(w\) with 112 support terms and coefficient
\(\ell^1\)-norm 124.

Under (3), its exact integral wedge coordinates are
\[
\overline w=(-1,-3,-3).
\tag{7}
\]
Consequently
\[
\Psi_{\mathrm{cyc}}(\overline w)=-7\equiv1\pmod2.
\tag{8}
\]
Equations (6) and (8) prove
\[
w\notin\sum_{i=0}^4L_i(\Lambda^2M).
\tag{9}
\]

As an independent finite-dimensional audit, the 15 induced columns—five
operators on three wedge basis vectors—have rank 2 over \(\mathbb F_2\).
Adjoining (7) raises the rank to 3.

The distinction from the earlier nontrivial three-point action is essential.
For
\[
c=(1\ 2),\qquad t=(0\ 1\ 2),
\]
the same residual has coordinate sum \(-32\), which vanishes modulo 2.
Killing \(c\) in (2) changes which infinite wedge pairs collide in the
finite quotient and exposes the missing parity.

## 3. The known affine span

Let \(u_0,u_1\) be the two one-hop homogeneous directions, let \(w_0\) be
the 23-entry \(L_0\)-coupled remote syzygy, and let \(z\) be the new
16-entry \(L_1\)-coupled syzygy. For each
\[
(a,b,d,e)\in\mathbb F_2^4,
\]
replay the first-layer correction
\[
x^{00}+a u_0+b u_1+d w_0+e z
\tag{10}
\]
nonlinearly and evaluate
\[
(\Phi_\infty,\Phi_3,\Phi_4,\Psi_{\mathrm{cyc}}).
\]
The exact table is

| \((a,b,d,e)\) | four bits |
|---|---|
| 0000 | 1111 |
| 0001 | 0001 |
| 0010 | 0011 |
| 0011 | 1101 |
| 0100 | 0100 |
| 0101 | 1101 |
| 0110 | 1000 |
| 0111 | 0001 |
| 1000 | 0100 |
| 1001 | 1010 |
| 1010 | 1010 |
| 1011 | 0100 |
| 1100 | 1011 |
| 1101 | 0010 |
| 1110 | 0101 |
| 1111 | 1100 |

No row is 0000. Therefore the four functionals separate every mod-2 class
in the currently known four-direction affine span.

This finite table is not a classification of the full homogeneous syzygy
module. A fifth direction outside this span may still change all four bits.

## 4. Consequence and frontier

The source-coupled syzygy proves that the first three functionals are
incomplete. The cyclic quotient proves that this particular escape still
fails at degree two. Together with the table, the next exact alternatives
are:

1. construct another compact source-coupled syzygy outside the four known
   directions and test whether it kills all four bits; or
2. promote the four finite-quotient functionals to a global statement about
   the complete first-layer syzygy module.

The orbit-balance and binomial-forest machinery should be used to generate
new source boundaries algebraically. Radius-first expansion is neither a
proof of nonexistence nor an efficient path constructor.
