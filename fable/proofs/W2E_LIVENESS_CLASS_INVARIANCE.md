## 2. Method: why the windows had to be rebuilt

`period_two_baseline_liveness.analyze_reps` enumerates gauge representatives
from a **ball**, truncated at caps 4/2/3/3, and early-exits at the first live
window. That is fine for its own purpose (exhibiting liveness) but is
**not a fair comparator**: the two members of a class get different numbers
of representatives per slot. Measured directly on class 2, the `h1` coset of
`S0` has 3 elements in `ball(10)` and the `h1` coset of `S1` has 2 — so an
`exists`-over-`h1` verdict hands `S0` an extra chance for a reason that is
pure word length.

This checker replaces the ball by a **centralizer index**. Each gauge slot's
condition is `h * base * h^-1 == target`, whose solution set is exactly
`h_base * C_Q(base)`; for the hyperbolic bases occurring here `C_Q(base)` is
infinite cyclic, generated by the primitive root `zeta` of `base` (free-product
centralizer theorem). So the windows are indexed by an integer,

```text
h(k) = h_base * zeta^k,      |k| <= K,
```

and both members get exactly `2K+1` windows per slot. A control verifies,
for every slot of every chain, that **every** conjugator found in `ball(10)`
really is `h_base * zeta^k` — so the index is not a sub-sampling of the
gauge orbit, it is a re-coordinatisation of it.

### 2.1 The alignment

With `R`, `U` fixed and `S' = gamma S gamma^-1`:

```text
h0' = h0             (h0's condition mentions R only)
h2' = h2 gamma^-1    (h2 S^-1 h2^-1 = R^-1 U      is preserved)
h3' = h3 gamma^-1    (h3 S  h3^-1  = U g t g^-1   is preserved)
g'  = g              (g is found from U and cyc S alone — hence class-shared)
```

Each identity is re-verified by string arithmetic inside the checker, and
`g_shared: true` is reported for all five classes. Note this already
**disposes of W2D (d.5)'s worry inside a class**: the terminal conjugator `g`
does not move when the `S` representative does.

The `h1` slot has **no canonical image** — `h1 R^-1 h1^-1 = B^-1 S`, and
`B^-1 (gamma S gamma^-1)` is not a translate of `B^-1 S`. Since the five
lifting operators do not depend on `h1` at all (only the defect does), `h1`
is the residual gauge, and the comparison is reported two ways:

- **h1-reduced**: `P(k0,k2,k3) = exists |k1| <= K` solvable — one existential
  per side, symmetric window counts;
- **strict**: every index `(k0,k1,k2,k3)` compared for itself, each member
  using its own shortest `h1_base` with the shared `zeta_{R^-1}`. Both sides
  are then a single concrete linear system, so **a strict mismatch is a
  decidable counterexample with no existential on either side.**

Because `gamma` is only defined modulo `C_Q(S0)`, a second `gamma` is
available; the checker re-runs the comparison with it.

## 4. Theory: the transformation law, and why no intertwiner exists

### 4.1 Closed forms (machine-verified inside the checker)

Write `bridge = h2 + U^-1 h3`, `d_r = A - R`, all in the group ring of
`Q = <c,t | c^2>` acting on `M = Z[Q/<c>]`. Unwinding
`build_operators_general` with the two conjugacy identities
`h2 S h2^-1 = U^-1 R` and `h3 S h3^-1 = U w` (`w = g t g^-1`) gives

```text
L0 = -( U^-1 + bridge*S ) * d_r
L1 =  bridge * ( B - S )
L2 =  1 - U^-1 R
L3 =  U^-1 - w
L4 =  w - 1
```

`L2, L3, L4` mention `S` **not at all**. Substituting `S -> gamma S gamma^-1`
together with the alignment `h2 -> h2 gamma^-1`, `h3 -> h3 gamma^-1` (so
`bridge -> bridge * gamma^-1`) gives, with `gi = gamma^-1`:

> **Transformation law.**
> ```text
> L0' = -( U^-1 + bridge*S*gi ) * d_r        L2' = L2
> L1' =  bridge * ( gi*B - S*gi )            L3' = L3,  L4' = L4
> ```

Both closed forms and both primed forms are asserted by the checker for every
aligned `(h2, h3)` window of every class pair, and pass
(`transformation_law_verified: true`).

Read off the shape: **the alignment right-multiplies only *part* of each
operator.** In `L0` the `bridge*S` summand picks up `gi` and the `U^-1`
summand does not. In `L1` the `S` summand picks up `gi` on the **right** and
the `B` summand picks up `gi` on the **left**.

### 4.2 The obstruction, isolated

Comparing against the one transformation that would have sufficed — right
multiplication by a single unit — the defects are

```text
E1 := L1' - L1*gi = bridge * ( gi*B - B*gi )                       = bridge * [gi, B]-type term
E0 := L0' - L0*gi = U^-1 d_r (gi - 1) - bridge*S*( gi*d_r - d_r*gi )
```

Both identities were verified exactly on all five class pairs, and both terms
are **nonzero** in every case (`gamma = Tctt` commutes with neither `B` nor
`R`).

### 4.3 Why right multiplication would have sufficed, and why it fails

`M = Z[Q/<c>]` carries the **left** `Q`-action (`c_vertex` takes right cosets
`q<c>`; `apply_operator` multiplies on the left). Left multiplication by a
group element therefore **permutes the coset basis of `M`**, so for any unit
`u in Q`:

```text
(L_i * u) * M  =  L_i * (u * M)  =  L_i * M,
```

and the one-hop candidate set transports by `v -> u^-1 v` (the checker's
`one_hop_system` builds candidates as `c_vertex(g^-1 d)`, which is equivariant
for left translation). Hence: **if all five operators transformed by right
multiplication by one common unit and the defect were unchanged, one-hop
solvability mod every `p` would be identical** — the two systems would be the
same matrix up to a relabelling of columns and rows.

That is exactly what fails:

- `L2' = L2`, `L3' = L3`, `L4' = L4` force the common unit to be `u = 1`;
- but `L0' != L0` and `L1' != L1` whenever `gamma != 1` (`E0`'s first summand
  `U^-1 d_r (gi - 1)` is already nonzero).

The checker probes `u in {1, gamma, gamma^-1}` explicitly and reports
`no_uniform_right_unit_intertwiner: true` in every class.

**Theory verdict: OBSTRUCTED.** The natural intertwining argument does not
merely fail to close — the obstruction is exhibited in closed form and is
nonvanishing on every class pair here (verified). Its summands vanish only
under hypotheses the census pair does not satisfy: `E1` needs `gamma` to
centralise `B`, and `E0`'s first summand `U^-1 (A - R)(gi - 1)` is the
four-term element `U^-1(A*gi - A - R*gi + R)`, zero only if `gamma = 1`
(the alternative, `A = R`, is false). Measured: `B` and `R` are each their
own primitive root (`|zeta_B| = 8`, `|zeta_R| = 9`), they do not commute, and
`zeta_B^k` is no power of `zeta_R` for `|k| <= 8` — so the two maximal cyclic
centralisers are distinct, hence (free-product) intersect trivially, and no
nontrivial `gamma` centralises both. *Nonclaim:* whether `E0`'s two summands
could cancel each other for some exotic `gamma` is not analysed in general;
here they demonstrably do not.

### 4.4 Both halves of the system move

At every mismatching window the defect moves too, and a cross-test isolates
the responsibility. Writing `(D, O)` for "defect `D` against operator system
`O`", at the first mismatching window of each of the five classes:

| pairing | class 0 | class 1 | class 2 | class 3 | class 4 |
|---|:--:|:--:|:--:|:--:|:--:|
| `(D0, O0)` = member0 | solvable | solvable | solvable | solvable | solvable |
| `(D0, O1)` | no | no | no | no | no |
| `(D1, O0)` | no | no | no | no | no |
| `(D1, O1)` = member1 | no | no | no | no | no |

So swapping **either** the defect **or** the operator system alone already
destroys one-hop solvability: the two changes are not compensating halves of
a hidden symmetry. `L2, L3, L4` are identical in every case; only `L0, L1`
move, exactly as the law predicts.

### Scope and nonclaims

- **`NOT-LIVE` is inconclusive.** W2b's doctrine is inherited: a chain that
  shows no live window may be live at an untested one. Therefore the
  **chain-level** question "is `exists`-window liveness a class invariant?"
  is **not** settled here, and the chain-level verdict differences in classes
  0, 1, 3, 4 are not by themselves counterexamples. Only the strict
  window-level mismatches of §3.2 are, and they are what the verdict rests on.
- **One conjugation.** All five class pairs at cap 12 realise the *same*
  `gamma = Tctt` and the same `(S0, S1)`; the census offers no second
  conjugation pair at this cap. So the empirical half is "one `gamma`, five
  `U`s", not a survey of conjugations. The theory half (§4) is `gamma`-generic.
- **Ceilings, not budgets.** Cap 12, `GPAD 5`, `K`, and `ball(10)` are
  ceilings. They can only under-report live windows; they cannot manufacture
  a mismatch, because a mismatch is a pair of completed linear-algebra
  decisions.
- **The alignment is the canonical one, not the only conceivable one.** §4
  rules out a *module intertwiner over this alignment*. It does not rule out
  some unrelated correspondence between the two chains' lift problems.
- No claim about the free-group depth-four class, the bridge, AK(3), stable
  AC, or AC. Nothing here is a statement about lifting or trivialisation.

## 6. Consequence for the uniform argument (W2D d.1)

W2D (d.1) posed the index-set question as a choice between an enumeration of
chains (106 at cap 17, growing) and an enumeration of invariant triples (31 at
cap 17, growing more slowly), and (d.4) identified this note's question as the
switch between them. **The switch is off.** Layer-1 liveness reads the literal
`S` through `L0 = -(U^-1 + bridge*S)(A-R)` and `L1 = bridge*(B-S)`, and the
class alignment does not act on those two operators by anything a module
automorphism can undo. So a uniform layer-1 argument may **not** be quantified
over `(cyc R, cyc S, cyc U)` triples; it must retain the `S` representative,
whose multiplicity inside one class is unbounded (W2D d.4 already lists six
representatives of `cyc(S) = TcTcttc` by cap 15). Together with (d.5) — the
terminal conjugator `g` cannot be fixed either, though §2.1 shows `g` at
least does not move *within* a class — both of the cheap reductions are gone.

What survives, and is the concrete revised specification: the `S`
representative is **not free**. By the uniform pinning lemma (W2D c.1) it is
`S = B * u2 rho2 u2^-1` with `u2` a literal prefix of `B^-1`, so the
representatives inside one `cyc(S)` class are indexed by the level-2
parameters `(k2, p2)` of the six-integer normal form — and the class members
here are exactly `(k2, p2) = (0, 2)` versus `(2, 3)`, matching W2D (c.3)'s
published parameter table. The uniform obligation is therefore not
"uniform in `cyc(S)`" (false) nor "uniform over an unstructured infinity of
representatives" (hopeless), but **uniform in `(k2, p2)`** — a prefix length
and a rotation index, exactly the two moves W2D (d.2) already identified as
the ones a uniform obstruction must be stable under. The transformation law
of §4.1 is the explicit action of a change of representative on the operator
system, and is the object such an argument now has to be uniform against.
