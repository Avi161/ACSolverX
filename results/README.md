# results/

`python run.py --config configs/<name>.toml` writes `results/<run name>/` here:

- `paths.jsonl`: one record per row (`id`, `solved`, `kind`, `aut_assisted`, `cost`, `sub_moves`, `elem_moves`,
  the certificate, `seconds`), written only after the certificate replays on the row. A rerun skips rows already
  in the file; `--fresh` starts over.
- `summary.json`: solved, `ac_path` / `aut_assisted` / `stable_cert` counts, cost, wall time and path lengths in
  substitution and elementary moves per kind.
- `config.json`: the config the records were made with.

`paths.jsonl` is gitignored (the certificates are regenerated by rerunning the config); the `summary.json` and
`config.json` of every run quoted in `README.md` and `docs/RESULTS.md` section 0 are tracked. Each run's command is
`python run.py --config configs/<file>.toml --set name=<run> [--set ...]`, as listed in RESULTS.md section 0
(`config.json` holds the full config).
