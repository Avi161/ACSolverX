# Ryan Zang's CoV-gate search at 100,000 nodes (no length cap)

Ryan's best-first search with CoV gates ([ryanzang04/Stable-ACSolver](https://github.com/ryanzang04/Stable-ACSolver),
`scripts/ms640_cov_gates.py`, commit `148a3de`), run with our numba port `benchmark/ryan/cov_gates_numba.py`.

- **Benchmarks and gates:** MS640 and ladder100 (`ladder_default.csv`), all six gates, budget 10^5 pops a search.
  bench60 is read off its MS640 rows.
- **No length cap.** Ryan's code caps relators at 24 letters and the total at 48; here there is no cap. The longest
  relator generated by any search is reported, and reaches 84.
- **Run:** one AWS spot m7i.16xlarge, 64 workers, about 4 minutes for all 4,440 searches (see `ops/aws/ledger.md`).

```bash
python benchmark/ryan/run_all.py --out results/ryan_1e5 --max-nodes 100000 --workers 64
python benchmark/ryan/summarize.py results/ryan_1e5 --md results/ryan_1e5/SUMMARY_TABLE.md
NUMBA_CACHE_DIR=/tmp/nc python -B benchmark/ryan/verify_paths.py results/ryan_1e5 --out results/ryan_1e5/VERIFY.json
```

## Same algorithm

The port was checked in two steps:

1. **Python port against Ryan's JAX code** (`benchmark/ryan/check_port.py`):
   - 194,746 children compared, 0 mismatches;
   - 60 whole searches (10 rows x 6 gates) identical in nodes, states, CoV counts and path.
2. **Numba kernel against the Python port** (`benchmark/ryan/check_numba.py`):
   - with Ryan's 24/48 caps: 216 searches identical, hard rows included;
   - with no caps: 24 hard searches identical.

The kernel is about 22 times faster than the Python port.

## Certificates

Ryan's CoV move takes z := W (or W^-1) for a cyclic window W of one relator. The rest of that relator holds the
eliminated generator once, so the move is an automorphism of F2, by the same argument as Elliot's single CoV.

`VERIFY.json` replays every solved path: substitution steps are reduced products of rotations, and CoV steps stay in
the Aut(F2) orbit (`acx.aut.orbit_key`). Everything passes, so every solve is an AC path via Aut.

## Fields (`<bench>__<gate>.jsonl`)

| field | meaning |
|---|---|
| `nodes_visited` | pops, as in Ryan's script |
| `path_length` | `path_sub_moves` + `path_cov_moves` |
| `max_relator_len` / `max_total_len` | longest relator / total length on the path |
| `max_relator_len_generated` | longest relator anywhere in the search |
| `path`, `actions` | the solution |

The fields of Ryan's own records are kept as well.

The CoV enumeration at a gate opening is not charged, as in Ryan's script; nodes count pops only.
