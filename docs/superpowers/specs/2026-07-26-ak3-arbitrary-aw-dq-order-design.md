# AK(3) arbitrary A--W / D--Q order design

Date: 2026-07-26

## Objective

Close the non-source deletion order

\[
\text{arbitrary A--W relative product}
\;\to\;D\text{ deletion}
\;\to\;\text{mixed Q deletion}
\]

at all six D-tail checkpoints.

## Quotient naturality

An A--W edge changes neither the D-row nor the separately retained
Q-row. Therefore the fixed D-deletion quotient sends Q to exactly its
baseline image, independently of the relative conjugator and target
direction.

Only the mixed rows

\[
Q_{-1,+1,\delta}=q^{-1}WD^\delta
\]

are primitive after D deletion. Their joint normal closure with D is
the same as the Result 47 based pair \((S,D)\), so use that fixed
quotient \(\pi_\delta\) and write its exact surviving baseline A--W
pair as \((a,w)\). A fixed ambient rank-two coordinate places this
pair at floor 23.

## Endpoint formula

For \(c=\pi_\delta(u)\), the two target directions descend exactly to

\[
(a c w^\sigma c^{-1},w),
\qquad
(a,w c a^\sigma c^{-1}).
\]

Each is one multiplication by a conjugate from \((a,w)\), hence a
finite classical AC sequence in the fixed coordinate. Other
straightener outputs are only claimed Aut-equivalent, and therefore
stably in the same corridor.

## Boundary

This closes only the specified D-then-mixed-Q order. A newly primitive
changed carrier, a primitive pair involving it, nonmixed Q rows,
intervening traffic, and arbitrary z-dependent changed-row-first
A--W deletion remain open.
