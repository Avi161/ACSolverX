# AK(3) Minimum-Tail All-Target Fox Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Decide the repositioned minimum-tail Fox equation for every
target \(g\in G\).

**Architecture:** Classify the two-point right-hand side by HNN-tree
incidence, reduce every admissible path to the \(Q\)-coset module, and
separate its moving support from a fixed central coset by a folded
fiber-product theorem.

**Tech Stack:** Markdown proof, pure Python, amalgam normal form,
free-product Stallings cores, Bass--Serre theory, group-ring coset
modules.

## Global Constraints

- All chains have finite support.
- Left-coset and right-multiplication conventions must be explicit.
- A bounded path census is evidence only and cannot prove the theorem.
- No AC graph search.
- AK(3) and the general conjectures remain open.
