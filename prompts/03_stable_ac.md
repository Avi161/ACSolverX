# Prompt 03 — Stable AC: search the AC4/AC5 move space directly

> **Read [`00_operating_contract.md`](00_operating_contract.md) first and adopt it in full.** This prompt adds the stable-AC content. Have your plan reviewed by `ac-advisor` before implementing — the stable/unstable distinction is where the most subtle unsound arguments hide.

## The target, precisely

A balanced presentation `⟨x₁,…,xₙ | r₁,…,rₙ⟩`. The **AC moves** are AC1 (`rᵢ ↦ rᵢrⱼ`), AC2 (`rᵢ ↦ rᵢ⁻¹`), AC3 (`rᵢ ↦ g rᵢ g⁻¹`), plus free/cyclic reduction. The **stable moves** add:

- **AC4 (stabilize):** `⟨x₁,…,xₙ | r₁,…,rₙ⟩ ↦ ⟨x₁,…,xₙ,z | r₁,…,rₙ, z⟩` — adjoin a fresh generator `z` and the relator `z`.
- **AC5 (destabilize):** the inverse, allowed **only** when the relator being deleted is literally `z^{±1}` and `z` occurs in no other relator. (That precondition is the whole subtlety.)

**Stable AC conjecture:** every balanced presentation of the trivial group is stably AC-trivial (reachable to `⟨x|x⟩`-type standard form under AC1–AC5). Since stabilization only *adds* moves, AC-trivial ⇒ stably AC-trivial; the converse is the open gap. **A stable counterexample is strictly stronger and harder to exhibit than a plain one** — it is automatically a plain counterexample too, but a plain counterexample could still be stably trivial. Stable AC equivalence corresponds to **3-deformation** equivalence of the presentation 2-complexes (Hog-Angeloni–Metzler–Sieradski; move-level conversion in Lackenby arXiv:2606.06122 §2 — see `results/stable_ac/theory/OBSTRUCTION_BARRIER.md`), so it is the more topologically canonical statement.

**The mission.** Per `ac-advisor.md`: **no computational method has ever searched the stable (AC4/AC5) move space directly** — Lisitsa's 2025 closing challenge, confirmed across the whole literature. Miasnikov's genetic algorithm tried flat stabilization and found *no benefit*; the Two-Hump work never uses it; Lisitsa's ATP formalizes AC4 but proves only non-stable sequences. **Closing this gap is precisely this project's reason to exist.** The evidence says naive AC5-as-a-flat-action fails — so stabilization must be proposed in a *targeted* way (Lemma-11 / change-of-variables–driven), not as an undirected extra action.

## What a genuine stable-AC result looks like

- **A verified stable trivialization** of a hard candidate (a class from the 124, or AK(3)): a Lemma-11 / CoV chain plus an AC path, independently replayed by `experiments/stable_ac/verify_results.py`, with every automorphism step certified as a genuine F₂ automorphism (Nielsen reduction). This proves *stable* triviality — never conflate it with unstable AC-triviality; the CoV chain's move count excludes the unbounded Lemma-11 cost (Red Line 5).
- **A thickenability certificate.** Lackenby: a *thickenable* balanced trivial-group presentation satisfies the AC conjecture (Thm 1.3), and stable ACC ⟺ every such presentation reaches *some* thickenable presentation by stable AC moves. So "is this state thickenable?" (Neuwirth — decidable) is a legitimate, decidable **milestone predicate** for a stable-AC search: reaching any thickenable state settles the instance. Caveat: the Thm 1.1 vs 1.2 gap proves the conversion is non-elementarily long in the worst case, so "reach thickenability" is a valid target, not a cheap one. A false-positive thickenability verdict silently prints a false proof — cross-check every positive against Regina.
- **A new theorem**, extending `literature/proofs/STABLE_AC_NEW.tex`. That file is a living, status-tagged document (`[PROVEN]`, `[CHECKED:N]`, `[CONJECTURE]`) already hardened by an adversarial theorem-hunt that rejected 9 of its own 9 fresh candidates — so the bar is high and the obvious vein looks mined. The checkable yield so far: the stable ambient automorphism principle (Thm 3), orbit-escape needs `n_subs ≥ 2` (checked 6856 rows), the exact length-change laws, and the refutation of the floor conjecture. A new result must survive the same hostile-referee gate.

## What does NOT count (stable-AC-specific traps)

Beyond the contract's ten red lines:

1. **The *unstable* ambient automorphism principle is not a theorem** (Red Line 2, the single most common unsound step). `(R,S) ~AC (φR,φS)` is asserted without proof by MMS02 and *conjectured false* by Panteleev–Ushakov. Only the **stable** form `(R,S) ~st (φR,φS)` for trivial-group presentations (`PROOFS.tex` Thm 3, proved via Lemma-11 chains over Nielsen generators) and the *end-at-standard* collapse (Lackenby Thm 6.4 / P–U Lemma 3.1 — which needs the derivation to already reach the standard tuple) are theorems. Any argument applying an automorphism to both relators as an *unstable* AC move is BLOCKED.
2. **Naive flat stabilization is a known dead end.** Do not propose AC5-as-an-undirected-extra-action — Miasnikov already showed it yields no benefit. Stabilization must be Lemma-11 / CoV-*directed*. (The plain-stabilization baseline is worth running once as a *baseline*, ranked lowest, precisely because it is "the dumbest possible thing" — but never as the main bet.)
3. **A CoV solve proves stable triviality only** (Red Line 4). Its `path_length` is not an unstable-AC proof length. And CoV does not consistently help — its value is best-of-many restart selection.
4. **No invariant at the usual layers can be a stable-AC obstruction.** `results/stable_ac/.../OBSTRUCTION_BARRIER.md`: all balanced trivial-group presentation complexes are contractible with `Wh(1) = 0`, so no abelian / quotient / homological / π₂-module / torsion invariant separates stable-AC classes. The normal closure `⟨⟨R,S⟩⟩ = F₂` is constant across all of them; `μ` (the Aut-orbit floor) is provably *not* CoV-invariant. The only uncollapsed layer is 3-deformation type — i.e. exactly the open stable-AC question — and the only decidable proxy is thickenability. **Do not spend effort inventing an invariant at those layers; it is provably hopeless.**
5. **`μ = 13` is never a removal.** The stable-solve finish line is `μ ≤ 12` (then MM03 gives AC-triviality of the orbit floor); `μ = 13` cannot certify triviality because AK(3)'s length-13 class provably holds ≥ 2 Aut-orbits (Red Line 9).

## The levers (with measured first results)

Grounded in `experiments/stable_ac/`, `results/stable_ac/`, and `literature/proofs/`:

1. **Targeted Lemma-11 change of variables (the core mechanism).** Lemma 11 (Two-Hump §9): `⟨…,y | …, y⁻¹w⟩ ~st ⟨… | …⟩` with `y ↦ w`. The project's directed batching is the 5-step CoV transform (S1 stabilize `z⁻¹w`, S2 substitute `w→z`, S3 isolate a generator, S4 destabilize, S5 relabel — `cov.py`, `PROOFS.tex`). This is *literally a stable-move supermove*. Proposition A (`MU_CRITERION.md`): any gated subword-CoV hop (`n_subs ≥ 1`) is a stable AC move. Only `n_subs ≥ 2` hops leave the input's Aut-orbit (`PROOFS.tex` Thm 1). Pre-filter candidates with the proven per-relator cap-fit bound.
2. **The μ-ladder / orbit-floor search — a direct stable-move search.** `mu_ladder_big.py` climbs a beam of gated-CoV (stable) hops, scoring states by `μ` (Aut-orbit floor, `autcanon.py`). Findings on the 124 (`MU_SCAN_FINDINGS.md`): **35 of 124 classes strictly descend** their orbit floor under CoV hops; best floor reached is **15** (not yet the μ ≤ 12 finish line), and all 35 chains are independently re-derived (35/35, 0 failures). The **criterion**: reach `μ(Q') ≤ 12` on any class and it is stably AC-trivializable (`P ~st Q' ~AC trivial` via MM03). This is the most concrete "search the stable move space directly" instrument that exists — push it, but honor the closure discipline (a global best-first heap over the open set proves "no orbit below μ" in a way a rung-local beam never can — `rung-local-beam-abandons-the-low-shell` lesson).
3. **Thickenability (Neuwirth) as a decidable milestone** — the one route that could *close* a candidate outright (see above; and [`01_ak3.md`](01_ak3.md) lever 1 for AK(3) specifically). `NEUWIRTH_FEASIBILITY.md` gives a GO verdict; leaves numba for 3-manifold topology; every positive cross-checked against Regina. A useful sub-deliverable: construct a 2-generator *known-NOT-thickenable* example (none exists in the literature the memo found) as a sharp test.
4. **Stall-triggered stable escape** — `stall_escape.py` (shipped): apply a CoV when the greedy plateaus, resume in new coordinates; **12/22 vs 10/22 at matched budget, 0 losses**. The closest running approximation to "cross the valley with a stable move."
5. **Plain-stabilization baselines (mentor's ideas 2–3)** — `⟨x,y|r1,r2⟩ → ⟨x,y,z|r1,r2,z⟩` at 3/4/5 generators, handed to the general-`n` solver (`solvern.py`). Ranked lowest, run once as the honest baseline the mission must beat. The static rank-4/5 pilot (`run_static_rank.py`) solved 18/110 jobs — easy-ladder rows only, AK(3) and hard cases 0.
